RUST FURNACES — дополнение к MineRust (Minecraft 1.12.2 Forge)
================================================================

Нужно: Forge 1.12.2 + мод MineRust (minerustaddons) в папке mods. Мод ставится на сервер И на клиенты.

БЛОКИ (вкладка "Декорации" в креативе)
- "Печь" — обычная печь с моделью печи MineRust и интерфейсом как в Rust.
- "ADMIN печь" — та же печь с надписью ADMIN, неломаемая.

ОБЫЧНАЯ ПЕЧЬ (ПКМ)
- FUEL — топливо, INPUT — 2 слота для ресурсов, OUTPUT — 3 слота результата.
- Кнопка TURN ON / TURN OFF. Печь плавит только по сейвам из ADMIN печи.
- Когда плавить нечего (нет ресурса/топлива/места в OUTPUT), печь сама выключается.

ADMIN ПЕЧЬ
- ПКМ — работает как обычная печь.
- SHIFT + ЛКМ — настройки плавки (только для OP / владельца одиночного мира).

НАСТРОЙКА СЕЙВА
1. INPUT — что плавится (количество в слоте = сколько тратится за одну плавку).
2. FUEL — чем топить (количество = сколько тратится). Пусто = без топлива.
3. OUTPUT — до 3 результатов (количество = сколько получится).
   Пример: 1 дерево в FUEL, 1 металл в INPUT, 2 металла + 3 угля в OUTPUT.
4. TIME (SEC) — время плавки в секундах (можно 2.5).
5. SAVE — сейв сразу применяется ко ВСЕМ печам на сервере.
   Если сейв с тем же INPUT и FUEL уже есть — он заменится.
- Справа список сейвов: выбрать строку -> EDIT (положит предметы в слоты для изменения) или DELETE.
- UP / DOWN или колесо мыши — прокрутка.
- Сейвы хранятся в папке мира: rustfurnaces_recipes.dat
- Предметы из слотов настройки возвращаются тебе при закрытии окна.

СБОРКА .JAR ЧЕРЕЗ GITHUB
1. Загрузи в репозиторий папку src (и этот README).
2. Если папка .github не загружается: на GitHub нажми Add file -> Create new file,
   имя файла: .github/workflows/build.yml и вставь туда содержимое build.yml.txt.
3. Вкладка Actions -> Build RustFurnaces -> дождись зелёной галочки ->
   внизу Artifacts -> RustFurnaces-jar (внутри rustfurnaces-1.0.jar).
4. Положи jar в mods вместе с MineRust.
